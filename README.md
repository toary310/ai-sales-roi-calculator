## アプリ概要

### 誰向けのアプリなのか

**AI Sales ROI Calculator**は、以下のような方々に向けて開発されたツールです：

- **営業マネージャー**: チームの生産性向上とAI導入効果を数値で把握したい方
- **経営陣・意思決定者**: AI投資の意思決定に必要なROIデータを求める方
- **IT部門・DX推進担当**: AI導入プロジェクトの効果測定と予算計画を立てる方
- **コンサルタント**: クライアントへのAI導入提案に具体的な数値根拠が必要な方

### 何ができるアプリなのか

このアプリケーションでは、以下のことが可能です：

1. **正確なROI計算**: 現在の営業データとAI導入コストから、投資収益率と回収期間を算出
2. **効果の可視化**: グラフやチャートで営業効率向上、売上増加、コスト削減効果を視覚的に表示
3. **業界別分析**: 業界特性と企業規模を考慮した精密な計算
4. **AI専門分析**: OpenAI GPTによる専門的な洞察とリスク分析
5. **レポート出力**: 計算結果をCSV形式でダウンロード可能

### どう役立つアプリなのか

- **意思決定の支援**: データドリブンなAI導入判断が可能
- **予算計画の精度向上**: 正確な投資回収期間の把握
- **ステークホルダーへの説明**: 具体的な数値根拠による説得力のあるプレゼンテーション
- **リスク軽減**: AI導入前の効果予測により、失敗リスクを最小化
- **競争優位性の確保**: 早期AI導入による市場での優位性確立

## アプリケーション起動方法

### 前提条件

- Node.js 18.0以上
- npm または yarn

### ローカル環境での起動手順

1. **リポジトリのクローン**

   ```bash
   git clone https://github.com/toary310/ai-sales-roi-calculator.git
   cd ai-sales-roi-calculator
   ```

2. **依存関係のインストール**

   ```bash
   npm install
   # または
   yarn install
   ```

3. **環境変数の設定**

   ```bash
   cp .env.example .env.local
   ```

   `.env.local`ファイルを編集し、必要な環境変数を設定：

   ```
   OPENAI_API_KEY=your_openai_api_key_here
   ```

4. **開発サーバーの起動**

   ```bash
   npm run dev
   # または
   yarn dev
   ```

5. **ブラウザでアクセス**

   以下のURLをブラウザに入力してアクセス：

   ```
   http://localhost:3000
   ```

## 用語説明

### ROI（Return on Investment）とは

**ROI（投資収益率）**は、投資に対してどれだけの利益が得られるかを示す重要な経営指標です。

#### 基本的な計算式

```
ROI (%) = (投資による利益 - 投資額) ÷ 投資額 × 100
```

#### 具体例

AI導入に500万円投資し、年間で700万円の利益向上があった場合：

```
ROI = (700万円 - 500万円) ÷ 500万円 × 100 = 40%
```

#### ROIの重要性

- **投資判断の基準**: 複数の投資案件を客観的に比較可能
- **効果測定**: 投資の成功・失敗を数値で評価
- **予算配分**: 限られた予算の最適な配分決定
- **ステークホルダー説明**: 投資の妥当性を明確に説明

#### 投資回収期間（Payback Period）

投資額を回収するまでにかかる期間：

```
回収期間 = 投資額 ÷ 月間利益
```

#### 本アプリでのROI計算の特徴

- **包括的な効果算出**: 売上増加、コスト削減、効率向上を総合的に評価
- **業界特性の考慮**: 業界別の平均値と比較した現実的な計算
- **企業規模の反映**: 会社規模による導入効果の違いを考慮
- **時系列分析**: 導入初期から安定期までの効果変化を予測
